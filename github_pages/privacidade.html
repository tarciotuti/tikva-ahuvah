Política de Privacidade

Última atualização: 20 de Novembro de 2026
Privacidade e Proteção: O Tikva Ahuvah é um aplicativo estritamente pessoal. Não coletamos, não rastreamos e não compartilhamos nenhum dado do usuário com terceiros ou anunciantes.

1. Armazenamento Local

Todos os registros criados no aplicativo (anotações devocionais, memórias e fotos) são armazenados localmente no banco de dados SQLite do próprio dispositivo do usuário.

2. Uso da API do Google Drive

O aplicativo permite ao usuário vincular opcionalmente sua conta pessoal do Google Drive para fins exclusivos de backup e restauração.

Para isso, solicita unicamente os seguintes escopos de acesso:

  • drive.appdata: permite salvar a cópia de backup na pasta protegida e oculta de dados do app;
  • drive.file: permite criar e gerenciar apenas os arquivos de backup gerados pelo próprio aplicativo.

O aplicativo não tem acesso a nenhum outro documento, pasta ou arquivo preexistente no Google Drive do usuário.

3. Compartilhamento de Dados

Nenhum dado é vendido, transferido ou compartilhado com terceiros. O uso dos dados das APIs do Google cumpre estritamente a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Gerenciamento e Exclusão

O usuário pode revogar o acesso do Google Drive a qualquer momento nas configurações do aplicativo ou pela página de permissões da Conta Google (myaccount.google.com/permissions).

5. Contato

Para esclarecimentos sobre esta política, o usuário pode contatar o suporte através das configurações do aplicativo.
